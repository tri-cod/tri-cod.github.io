### Week 9 Objectives:

- Explore the core features and functionality of Amazon CloudWatch and AWS CloudTrail.
- Understand how AWS resources can be monitored and how system logs are collected.
- Practice setting up CloudWatch Dashboards and Alarms to track resource performance.
- Learn how CloudTrail captures user activities and API requests for auditing and security monitoring.

  - Metrics
  - Logs
  - Dashboards
  - Alarms

- Completed the hands-on exercises covering Amazon CloudWatch and AWS CloudTrail in the Cloud Journey learning path.
