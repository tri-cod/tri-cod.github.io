### Week 8 Objectives:

- Explore the fundamental principles of Continuous Integration and Continuous Deployment (CI/CD) on AWS.
- Understand the roles of AWS Developer Tools, including CodeCommit, CodeBuild, CodeDeploy, and CodePipeline.
- Gain practical experience in creating an automated application deployment pipeline.
- Recognize how automation improves the software development and deployment process.

### Week 8 Achievements:

- Gained an understanding of Continuous Integration (CI) and Continuous Deployment (CD), as well as their importance in modern software development.
- Learned the responsibilities and main features of AWS Developer Tools, including:
  - AWS CodeCommit
  - AWS CodeBuild
  - AWS CodeDeploy
  - AWS CodePipeline
- Successfully created and maintained a source code repository with AWS CodeCommit.
- Set up automated build workflows using AWS CodeBuild and became familiar with how build specifications define the execution process.
- Deployed an application to Amazon EC2 through AWS CodeDeploy and checked the deployment results.
- Integrated CodeCommit, CodeBuild, and CodeDeploy into an end-to-end CI/CD workflow using AWS CodePipeline.
- Observed how updates to the source code can automatically initiate build and deployment stages, reducing manual operations and improving delivery efficiency.
- Completed the practical exercises involving AWS Developer Tools and gained hands-on experience in implementing CI/CD workflows on AWS.
- Developed a foundation for studying advanced DevOps techniques and automated deployment of cloud-based applications.
