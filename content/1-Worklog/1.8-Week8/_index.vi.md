### Mục tiêu tuần 8:

- Tìm hiểu những nguyên lý cơ bản của Continuous Integration và Continuous Deployment (CI/CD) trên AWS.
- Làm quen với các công cụ AWS Developer Tools, bao gồm CodeCommit, CodeBuild, CodeDeploy và CodePipeline.
- Thực hành xây dựng quy trình tự động hóa triển khai ứng dụng.

### Kết quả đạt được trong tuần 8:

- Hiểu được các khái niệm Continuous Integration (CI) và Continuous Deployment (CD), cũng như vai trò của chúng trong quy trình phát triển phần mềm hiện đại.
- Nắm được chức năng và nhiệm vụ chính của các công cụ AWS Developer Tools, bao gồm:
  - AWS CodeCommit
  - AWS CodeBuild
  - AWS CodeDeploy
  - AWS CodePipeline
- Tạo và quản lý thành công Source Code Repository bằng AWS CodeCommit.
- Thiết lập quy trình Build tự động với AWS CodeBuild và hiểu được cách Build Specifications điều khiển các bước thực thi.
- Thực hiện triển khai ứng dụng lên Amazon EC2 bằng AWS CodeDeploy và kiểm tra kết quả sau khi triển khai.
- Kết hợp CodeCommit, CodeBuild và CodeDeploy thông qua AWS CodePipeline để xây dựng một quy trình CI/CD hoàn chỉnh.
- Quan sát được cách những thay đổi trong Source Code tự động kích hoạt các giai đoạn Build và Deployment, qua đó giảm thao tác thủ công và nâng cao hiệu quả triển khai.
- Hoàn thành các bài thực hành liên quan đến AWS Developer Tools và tích lũy kinh nghiệm triển khai CI/CD Workflow trên AWS.
- Xây dựng nền tảng kiến thức để tiếp tục tìm hiểu các kỹ thuật DevOps nâng cao và quy trình tự động triển khai ứng dụng trên môi trường Cloud.
