### Week 11 Objectives:

- Understand the basic concepts of containerization and Docker.
- Learn about Amazon Elastic Container Registry (Amazon ECR) and Amazon Elastic Container Service (Amazon ECS).
- Practice building, storing, and deploying containerized applications on AWS.
- Explore the advantages of using containers for cloud application deployment.

- Gained an understanding of containerization and its advantages compared with traditional virtual machine-based deployment.
- Became familiar with the core components of Docker, such as:
  - Docker Images
  - Docker Containers
  - Dockerfiles
  - Docker Hub
- Built Docker Images and successfully ran containers in a local environment.
- Learned to create and manage private repositories using Amazon ECR.
- Successfully uploaded Docker Images to Amazon ECR for centralized storage and management.
- Understood the main components and workflow of Amazon ECS, including:
  - ECS Cluster
  - Task Definition
  - Service

- Practiced monitoring container deployments and troubleshooting common issues.
- Completed the practical exercises covering Docker, Amazon ECR, and Amazon ECS in the Cloud Journey learning path.
- Established a foundation for deploying scalable containerized applications and exploring cloud-native development.
