# Worklog Overview

This section presents my worklog throughout the AWS internship program, which lasted **12 weeks (approximately 3 months)**.

During this period, I followed a structured learning path to develop my knowledge of Amazon Web Services (AWS), cloud computing, and DevOps practices. Each week focused on a specific topic, combining theoretical learning with hands-on exercises to help me understand how AWS services work and how they can be applied in real-world scenarios.

Throughout the program, I studied fundamental AWS services, explored cloud infrastructure management, practiced application deployment, and learned about monitoring, automation, and containerization.

The following is a summary of the topics covered during the 12 weeks:

**Week 1:** [Introduction to AWS and Amazon EC2](1.1-week1/)

**Week 2:** [AWS Identity and Access Management (IAM)](1.2-week2/)

**Week 3:** [Amazon Virtual Private Cloud (Amazon VPC)](1.3-week3/)

**Week 4:** [Amazon Simple Storage Service (Amazon S3)](1.4-week4/)

**Week 5:** [Amazon Relational Database Service (Amazon RDS)](1.5-week5/)

**Week 6:** [Elastic Load Balancing (ELB) and Auto Scaling](1.6-week6/)

**Week 7:** [AWS CloudFormation (Infrastructure as Code)](1.7-week7/)

**Week 8:** [CI/CD with AWS CodeCommit, CodeBuild, CodeDeploy, and CodePipeline](1.8-week8/)

**Week 9:** [Amazon CloudWatch and AWS CloudTrail](1.9-week9/)

**Week 10:** [Serverless Computing with AWS Lambda and Amazon API Gateway](1.10-week10/)

**Week 11:** [Container Services with Docker, Amazon ECR, and Amazon ECS](1.11-week11/)

**Week 12:** [Final Review, AWS Solution Deployment, and Internship Summary](1.12-week12/)

By completing these weekly activities, I gradually strengthened my understanding of AWS services and gained practical experience in building, deploying, managing, and monitoring cloud-based applications. This internship also helped me develop a foundation for further learning in Cloud Computing and DevOps.
