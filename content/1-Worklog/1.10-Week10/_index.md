### Week 10 Objectives:

- Explore the basic principles and advantages of Serverless Computing on AWS.
- Understand the functionality of AWS Lambda and Amazon API Gateway.
- Gain practical experience in developing and deploying AWS Lambda functions.
- Learn how to create serverless APIs without having to provision or maintain servers.

### Week 10 Achievements:

- Developed an understanding of Serverless Computing and its advantages, particularly the ability to build and operate applications without directly managing server infrastructure.
- Became familiar with the essential components of an AWS serverless architecture, including:
  - AWS Lambda
  - Amazon API Gateway
  - Lambda Triggers
  - Amazon CloudWatch Logs
- Successfully developed and deployed AWS Lambda functions.
- Created a basic REST API by connecting Amazon API Gateway with AWS Lambda.
- Understood how API Gateway and other AWS services can invoke Lambda functions through an event-driven execution model.
- Practiced configuring Lambda Triggers and monitoring function execution using Amazon CloudWatch Logs.
- Completed the practical exercises involving AWS Lambda and Amazon API Gateway in the Cloud Journey learning path.
- Improved hands-on skills in developing serverless applications and gained a clearer understanding of how AWS serverless services integrate to support real-world application solutions.
