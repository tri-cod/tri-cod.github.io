### Kết quả đạt được trong tuần 10:

- Hiểu được mô hình Serverless Computing và những lợi ích của việc phát triển ứng dụng mà không cần trực tiếp triển khai, vận hành máy chủ.
- Nắm được các thành phần quan trọng trong kiến trúc Serverless trên AWS, bao gồm:
  - AWS Lambda
  - Amazon API Gateway
  - Lambda Triggers
  - Amazon CloudWatch Logs
- Tạo và triển khai thành công các AWS Lambda Functions.
- Xây dựng được một REST API cơ bản bằng cách tích hợp Amazon API Gateway với AWS Lambda.
- Hiểu được cách API Gateway và các dịch vụ AWS khác kích hoạt Lambda Functions thông qua cơ chế xử lý dựa trên sự kiện (Event-Driven Architecture).
- Có kinh nghiệm thực hành cấu hình Lambda Triggers và giám sát quá trình thực thi Function bằng Amazon CloudWatch Logs.
- Hoàn thành các bài thực hành liên quan đến AWS Lambda và Amazon API Gateway trong lộ trình Cloud Journey.
- Cải thiện kỹ năng thực hành phát triển ứng dụng Serverless và hiểu rõ hơn cách các dịch vụ Serverless của AWS phối hợp với nhau để xây dựng những giải pháp ứng dụng thực tế.
