### Week 7 Objectives:

- Explore the basic concepts and features of AWS CloudFormation.
- Gain an understanding of Infrastructure as Code (IaC) and its applications.
- Practice provisioning AWS resources through CloudFormation templates.
- Learn how to automate the deployment and administration of AWS infrastructure.

### Week 7 Achievements:

- Developed an understanding of Infrastructure as Code (IaC) and its role in making AWS infrastructure deployment more consistent and automated.
- Learned the essential sections of an AWS CloudFormation template, including:
  - Parameters
  - Resources
  - Outputs
  - Mappings
- Became more familiar with defining infrastructure configurations through YAML-based CloudFormation templates.
- Successfully built and deployed AWS resources using CloudFormation instead of configuring every resource manually.
- Understood the lifecycle of CloudFormation Stacks, including creation, modification, and deletion.
- Learned how Change Sets and Stack Events support the review and monitoring of infrastructure changes.
- Gained practical experience in automating AWS resource provisioning through reusable templates.
- Completed the CloudFormation practical exercises and strengthened knowledge of Infrastructure as Code practices within AWS.
- Established a foundation for exploring CI/CD workflows and automated application deployment in upcoming weeks.
