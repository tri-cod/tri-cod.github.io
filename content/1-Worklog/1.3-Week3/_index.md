### **Week 3 Achievements:**

- Developed a fundamental understanding of AWS and became familiar with its main service categories, including:
  - Compute
  - Storage
  - Networking
  - Database
  - Other related services

- Successfully created and completed the initial configuration of an AWS Free Tier account.

- Became more comfortable using the AWS Management Console, including navigating the interface, locating different services, and accessing their features.

- Installed and configured AWS CLI on the computer, including setting up:
  - Access Key
  - Secret Key
  - Default Region
  - Other necessary configuration settings

- Practiced using AWS CLI to perform several basic operations, such as:
  - Checking account and configuration information.
  - Retrieving the available AWS regions.
  - Accessing and exploring EC2 service information.
  - Creating and managing key pairs.
  - Checking information about running AWS resources and services.
  - Performing other basic command-line operations.

- Improved the ability to use both the AWS Management Console and AWS CLI to interact with and manage AWS resources.

- Gained initial hands-on experience with Amazon EC2, including launching instances, connecting through SSH, and attaching EBS volumes.

- Established a basic foundation in AWS services and resource management, preparing for more advanced cloud computing topics in the following weeks.
