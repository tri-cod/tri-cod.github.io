### Week 5 Objectives:

- Explore the core concepts and functionality of Amazon Relational Database Service (Amazon RDS).
- Identify the advantages of using AWS managed database solutions.
- Gain hands-on experience in deploying and maintaining Amazon RDS instances.
- Understand how to establish connections between cloud applications and relational databases hosted on AWS.

### Week 5 Achievements:

- Gained a clear understanding of Amazon RDS, its primary functions, and the benefits of using a managed database service on AWS.
- Learned the essential components and features of Amazon RDS, including:
  - Database Instances
  - Database Engines
  - Multi-AZ Deployment
  - Automated Backups
  - Database Snapshots
- Became familiar with the database engines supported by Amazon RDS, including:
  - MySQL
  - PostgreSQL
  - MariaDB
  - Microsoft SQL Server
  - Oracle Database
- Successfully deployed an RDS instance and applied the necessary network and security configurations.
- Established a connection to the RDS database using a database client and confirmed that the service was operating properly.
- Practiced setting up automated backups and generating database snapshots to support data recovery.
- Explored the use of Amazon CloudWatch to observe database performance and operational status.
- Completed the practical exercises related to Amazon RDS and developed hands-on skills in deploying and managing relational databases in the AWS environment.
- Developed foundational knowledge of connecting cloud applications to relational databases and preparing for more advanced AWS architecture topics.
