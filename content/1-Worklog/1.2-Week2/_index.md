### **Week 2 Objectives:**

- Gain a better understanding of the role of AWS Identity and Access Management (IAM) in managing users and access permissions.
- Learn about the main IAM components, including Users, Groups, Roles, and Policies.
- Practice creating and managing IAM resources within AWS.
- Explore fundamental AWS security best practices related to identity and access management.

### **Week 2 Achievements:**

- Gained an understanding of the purpose of AWS Identity and Access Management (IAM) and its role in controlling access to AWS resources.

- Learned about the functions of the main IAM components, including:
  - IAM Users
  - IAM Groups
  - IAM Roles
  - IAM Policies

- Developed a clearer understanding of the Principle of Least Privilege and how applying this principle helps strengthen security within AWS environments.

- Successfully practiced creating and managing the following IAM resources:
  - IAM Users
  - IAM Groups
  - IAM Roles
  - IAM Policies

- Learned how to assign permissions to Users and Groups through IAM Policies and verify the access rights configured for each account.

- Explored how Multi-Factor Authentication (MFA) improves account security and practiced enabling MFA for an AWS account.

- Understood the purpose of Access Keys and learned how to use and protect them when interacting with AWS through the CLI.

- Became more familiar with managing user identities and access permissions through IAM using both the AWS Management Console and AWS CLI.

- Completed the practical exercises and learning activities for Week 2, establishing a foundation for studying Networking and Infrastructure topics in the following weeks.
